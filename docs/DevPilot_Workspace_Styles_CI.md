## 所有登录用户的助手入口与后续开发切片

智能体/自定义助手默认对所有已登录用户开放，不要求管理员身份；保留会话认证、个人数据隔离与运维人员显式关闭能力。这不表示所有用户共享私人助手或凭据。当前本地未配置模型时，只验证管理功能，不宣称真实对话连通。

助手库新增“手动配置助手”：填写名称、描述、行为指令即可通过既有 owner-scoped API 保存，不需要先请求模型；既有对话式创建保留。提供需求梳理、数据设计、结果复核三种中英文角色预设，选择预设会明确覆盖当前描述和指令。它们只是对话建议，不自动读取金标、执行测试、接受结果或发布报告；报告仍从报告模块进入。

新助手不预选配置工具组和技能，模型留空沿用框架默认选择；可后续在助手设置中更改。**这不是无工具安全沙箱**：框架内置工具、MCP、记忆和模型提供商的数据边界仍由既有权限/运维配置控制。角色文字不能替代运行时授权。不要向普通对话粘贴秘密或隐藏金标。

表单只留在当前页面内存；提交时锁定编辑、重复提交和关闭，失败保留输入、显示通用错误，不回显内部异常。成功后刷新个人助手库。该切片不修改数据库 schema，不绕过认证，也不会在保存时发起模型请求。

## 侧边对话动画稳定性

完整浏览器回归发现重新打开历史侧边对话时偶发换行与滚动抖动。尺寸诊断证实：固定 280ms 的计时器先清除了内容宽度锁，但高负载下 CSS flex-grow 动画尚未结束，消息在狭窄面板中重新排版。修复前新增 900ms 慢动画回归可复现，未放宽“至多一个滚动位置”的既有断言。

ChatBox 在 layout effect 中先锁定宽度，以根分栏元素真实动画的 finished 状态完成解锁；取消、切换和卸载使旧完成回调失效。关闭内容也保留到实际动画结束；无动画时下一帧结束，不依赖计时猜测。减少动态效果模式直接使用最终布局，不施加临时 cqw 宽度锁，避免锁宽与真实分栏宽度（含分隔条差异）之间的额外换行；新增 MutationObserver 回归验证整个开合过程不出现该锁宽。普通、慢速及 reduced-motion 均覆盖首次打开、关闭、再次打开和宽度锁清理。此修复不改变消息内容或评测事实。

历史分页排序回归还补充了虚拟列表的同步：新页加入 50 条记录后，先滚动到测量完成的新尾部，再断言追问仍然可见。失败快照显示旧 viewport 仍停留在中间记录；本用例验证保留与排序，不把虚拟列表屏外未挂载误判为消息丢失。原追问可见性、旧时长及重新到首尾的检查均保留，不增加重试掩盖失败。
