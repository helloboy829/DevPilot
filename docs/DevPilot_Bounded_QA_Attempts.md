# DevPilot 有界单次 QA 响应采集核心

更新：2026-11-08。实现位于 `backend/app/evaluation/qa_attempts.py`。这是内部执行原语，不是新的执行 HTTP API、后台 Worker 或可用的完整评测任务。

## 已实现

- 接收已经渲染好的不可变请求、严格 JSON 输出映射、有限单次参数与运维配置；不接收预期答案或样本标签，不负责判分。调用方必须先进行独立运行准入，不能凭一个冻结计划就发送请求。
- 复用共享 `evaluation_client` / `PinnedEvaluationTransport`：目标 allowlist、DNS 检查与绑定、TLS 校验、无环境代理、零传输重试、不跟随重定向。新 `EvaluationPolicyError` 仍兼容既有 `ValueError` 捕获，仅区分传输派发前的策略拒绝。
- 一次调用最多一次应用层 HTTP 发送，不自动重发。单次总时限包括创建客户端、DNS、接收、解析与关闭；超时/断连属于 `delivery_unknown`，不能推断服务端没有处理，更不能据此安全重试。取消向上传播，响应和客户端释放；未来耐久调用方必须在发送前持久记录派发。
- 单次响应留存上限 1–1,048,576 字节，时限 100–300,000 毫秒，严格整数。拒绝非 JSON 媒体类型、SSE、压缩和非 2xx；仅完整、有效 UTF-8 JSON 中的非空白字符串可成为 `output_collected`。沿用严格 JSON 指针，拒重复键、NaN、非文本和缺字段；有界解析在线程中执行。
- 未显式指定 Accept-Encoding 时补 identity，避免 HTTPX 默认协商压缩；用户显式编码头不擅自覆盖，若返回压缩则明确拒绝，不做隐式解压。
- 留存缓冲最多上限＋1 字节用于检测超限；`body_bytes` 是采集器从已产出 raw chunks 留存的字节，**不是 socket 总收包、headers、HTTPX 预读、账单流量或请求/运行总预算**。Content-Length 不可信，实际流仍需检查。失败不留存部分正文为可用输出；部分已留存字节计数保留。
- 不可变内部结果只含技术类别、HTTP 状态、已留存字节、总耗时与敏感输出。输出不出现在 repr，不返回原正文/headers/URL/异常文本；但输出本身仍是敏感内部值，不能自动进入日志、聊天或公开 DTO。

## 不代表什么

`output_collected` 仅表示取得了可复核文本，**不是效果 PASS、准确率、平台签名证据或报告结论**。`elapsed_ms` 包含客户端与解析/关闭开销，不是 TTFT、token 速率、模型计算时长或可直接套用的运行统计口径。无流式、CV、自动裁判。

当前没有新增路由、调度接入、数据迁移、请求解密入口、运行授权或自动网络调用；旧调试/手动/定时调用路径未切换到本原语。新原语也没有全运行响应总预算、全局并发、租约、持久观测或重启恢复。后续必须先建这些边界，再接界面执行。
