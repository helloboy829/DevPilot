# DevPilot：加密输出证据与人工结果复核

日期：2026-11-08。本文只包含产品设计与工程合成测试，不包含客户场景名、历史业务指标、客户材料或密钥。

## 本轮范围与操作路径

在 **项目与数据 → 选择项目 → 人工结果复核** 中，先显式加载运行元数据，再选择组件 / 冻结计划 / 运行，加载样本列表，最后点击单条样本读取敏感内容。组件名、计划版本、样本 ID、输入 Q、实际 A、参考答案、来源、数据分层和技术状态同屏展示。复核者填写理由，选择“通过 / 不通过 / 待确认”，确认后追加一个人工决策版本。每条最多 100 个版本，旧版本不被 API 覆盖或删除。

**当前没有可从页面启动的持久 Worker。** 本轮交付输出留存与人工复核的后半段，不是完整自动化执行验收。现有老原型运行不自动导入，也不伪造为新的存证记录。没有记录时页面明确展示空状态，不会自动创建运行、调用目标、调用模型或填充业务数据。最近最多 200 次技术派发运行可选，样本分页默认为 100，服务端上限为 200。

## 数据边界与原子性

- App 新增迁移 **eval_0006**，只创建 evaluation_output_evidence 与 evaluation_case_reviews，不修改已部署迁移或 Harness ledger。
- EvidenceRepository.record_attempt 是内部接线点：未来独立准入的 Worker 在已确认派发提交并单次采集之后，传入 AttemptObservation。此处不读取请求明文、金标或输入，不发起网络，不提供“手工上传实际输出”的 HTTP 接口。
- 提取后的非空 UTF-8 输出文本与技术观测在同一事务提交；任何失败都不会留下半条成功证据。单条输出的 UTF-8 字节数受运行响应上限约束。非成功采集不允许附带输出。
- 输出和人工说明以独立 schema / kind 的 Fernet 信封加密，使用运维显式配置的 **DEVPILOT_REQUEST_ENCRYPTION_KEY**。不生成密钥、不退回 JWT / 模型密钥、不写入配置。请求信封不能被当成结果或复核信封解开。
- 信封绑定 owner、project、run、ordinal、sample、plan hash 及技术观测 hash，防止串项目、串运行或替换技术状态。公开 hash 是密文 hash，不是可离线猜测短答案的明文 hash。仅存提取文本，不保留原始响应 JSON、headers 或 wire 轨迹，不能称“完整原始响应归档”。
- 密文、凭据、Q/A、金标与说明不写入派发审计或公共列表；敏感输出不渲染为 HTML，来源不自动作为链接打开。
- 数据库写锁只覆盖状态核对、DB 写入和审计；加解密、完整内容校验在锁外线程执行，再在锁内重读完整快照，变化则拒绝。任何不确定提交都不返回成功，不得自动重发目标或覆盖证据。

这里的不可变是应用层 append-only、唯一键与审计边界，不承诺抵御拥有数据库和运维密钥的管理员篡改。密文会有存储开销，既有响应字节预算不是磁盘/账单/全局配额；全局准入与保留策略仍需后续开发。

## 人工决策不是技术成功

- output_collected / recording_finished 不是效果 PASS。
- 读取单条敏感样本时重新验证计划 hash、冻结 QA revision/hash、完整含金标的数据 hash、ordinal 对应的排序循环样本与输出信封。
- 追加人工决策须绑定读取到的 case_hash 和 expected_revision，必须显式布尔确认、提供不超过 2000 字的理由，要求样本已终止。双会话竞争只允许一个胜出，不默默覆盖。
- 缺少加密输出证据、HTTP 失败、未知交付等不能被标记“通过”；可记录不通过或待确认。老的纯技术观测如果没有输出证据，明确显示缺失。
- 列表统计只取每个 ordinal 最新人工决策，保留未复核数，不把历史修订重复计数、不丢弃失败/未审样本；**不是准确率或最终验收结论**。性能循环中的重复 ordinal 也不冒充独立效果样本。
- 本轮是项目 owner 的自复核，不是跨账号团队分配、领取、双人审批或仲裁。模型评审与报告 agent 后续只能建议，不能替人签署这些决策。

## API 与交互防护

| 路由（项目路径下） | 权限 / 内容 |
| --- | --- |
| GET /review-runs | read；运行元数据 |
| GET /review-runs/{run}/cases?offset=0&limit=100 | read；不查询密文、Q/A、金标或票据 hash |
| GET /review-runs/{run}/cases/{ordinal} | read + review；拒绝内部 agent；受控读取敏感内容并审计 |
| POST /review-runs/{run}/cases/{ordinal}/reviews | read + write + review；拒绝内部 agent；确认、内容 hash 与修订号校验 |

所有读取仍受 owner/project 限制；验证、存储和加密错误返回脱敏响应，并带 private / no-store。没有 execute、原始密文、输出手动覆盖、删除、自动重试等 HTTP 路由。

前端仅保留当前页面内存；切换项目、运行或样本清理敏感内容。刷新、编辑、提交撤销确认；写入使用同步 ref 锁，进行中禁止修改。未知写入后必须显式重新读取单条内容与最新修订，再确认；不根据猜测自动重试。组件卸载后到达的旧响应被丢弃。敏感内容不写 localStorage、sessionStorage 或聊天历史。

## 验证及后续

合成测试覆盖：先红后绿；输出与观测原子性；重复/过期派发拒绝；跨 owner/project/run/ordinal 信封绑定；输入、金标、计划、观测、密文变化拒绝；明文读取和人工写入审计；双连接修订竞争；实际提交成功后断连仍返回不确定；metadata SQL 不选择敏感列；eval_0005 升级、重复迁移及 Harness 保留；API 权限/内部 agent/脱敏错误；前端双击、确认撤销、未知写入、跨项目旧响应和 HTML 文本渲染；浏览器两轮人工复核、历史保留与无浏览器持久化。

本轮实际验证（隔离 Docker，全部使用合成数据）：

- 后端完整离线回归：**11,809 passed / 73 skipped**；新增存证/权限/升级测试与派发相邻回归 **124 passed**。
- 独立阻塞 I/O 门禁 **72 passed**；纯 evaluation/toolkit 领域测试 **15 + 58 passed**；全后端 Ruff 检查与格式检查通过。
- 前端 ESLint / TypeScript、**1,056** 项全量单测及生产构建通过，其中新增复核 DOM 交互测试 **7** 项。
- 新复核浏览器测试先暴露动态下拉标签的定位错误，改用实际 combobox 可访问性角色后复测通过。完整双 worker 回归另有两项旧助手/频道页面 5 秒可见性断言失败，失败快照分别处于加载态、已显示目标文案；保留原测试与超时，单独重复三轮 **21 passed**。随后按仓库 CI 的单 worker 配置完成普通 **188 passed**、认证恢复 **2 passed**，无用例排除、无重试。不据单次通过断言并行超时已被根治。
- 本地先做 SQLite 在线备份及完整性校验，再只增量更新 gateway/frontend 并刷新 nginx。App ledger 从 eval_0005 升至 eval_0006；所有原账号整行、旧评测行、Harness ledger、配置哈希、挂载及无关容器身份校验保留。6 个后端文件和 520 个前端源码哈希与运行容器一致。
- 所有现有账号通过只读浏览器验烟：个人助手、手动配置、五套主题、计划和复核元数据/入口；没有业务写入、模型调用或创建测试运行。首次启动验烟未通过，热身后重跑通过，未据一次失败宣称服务已经可用。

推送后必须核对该提交完整 SHA 的实际 Actions，不能用前一提交结果代替。当前运行环境没有配置工作模型及独立请求加密密钥；没有真实目标调用或真实模型验收，也没有 PostgreSQL 实例验收。

下一主线仍是：独立执行准入（同意、目标授权、请求/数据重验、跨进程全局配额）→ 有界 Worker 单次派发/采集/原子存证 → 取消/宕机保守终止 → 稳定分母的质量汇总与报告引用。之后补充团队仲裁、保留/删除、调度接入、CV、流式性能及真实可运行脚本导出。
