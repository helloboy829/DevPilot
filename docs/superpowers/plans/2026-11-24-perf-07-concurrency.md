# PERF-07 Bounded Concurrent Synthetic Worker

**Goal:** Extend the explicitly invoked PERF-06 synthetic-only worker to honor the frozen profile's bounded concurrency while preserving per-dispatch durability and no-resend semantics. This is ledger/evidence validation, not real target load testing.

**Architecture:** A single admission controller owns the frozen manifest and launches at most `min(concurrency, max_in_flight)` local tasks. Each task independently claims, ACKs, crosses its send fence, calls only the concrete in-process synthetic transport, and persists observation/evidence. The controller stops admitting new ordinals on the first terminal-policy failure, drains already-started tasks, and only then interrupts/finalizes the remaining population. Unknown after the durable start fence is never retried. Concurrency uses bounded task count and a shared conservative byte reservation (reserve request + max response before starting; release unused response budget after observation) so simultaneous calls cannot overspend the aggregate cap. No startup poller, public API, external transport, subprocess, or real destination is added.
