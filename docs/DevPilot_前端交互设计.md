# DevPilot 评测工作台交互设计

> 2026-11-06；目标 UI，**本轮未改前端代码**。当前为聊天工作台内的 component-tests 表单/JSON 页面。

## 2026-11-07 真实业务校准（待实现）

创建计划时首先选择“摸底 / 验收”；摸底显示 INFO_ONLY、限制与待补材料，不显示绿色“验收通过”或自动进入 accepted。指标卡分开显示接口/业务成功率、效果二值通过率、rubric 评分、结构合格率、数值误差，并可展开分子/分母/时间人群。空参考模板标“金标待补”，预测结构合格但无真值标“未验证数值准确性”。

人工复核面板并排呈现组件名/版本、case/turn、Q/实际 A/预期或 rubric、可信来源与时间快照、自动理由和错误；支持长文本折叠、差异/证据跳转、键盘上一条/下一条、暂存与争议升级。资料不足只能待补，不提供把 ERROR/NOT_RUN 变 PASS 的按钮。跨轮稳定性页展示各次结果，不挑最好一轮。

仓库/包名维持 DevPilot，界面副标题建议采用“AI 组件评测工作台”；恢复底座中英文文档路由不代表完成评测首页重构。[材料依据](DevPilot_历史材料分析与设计校准.md)。

## 2. 项目流程画布

~~~text
项目名 / 组件版本 / 总验收状态 / 权限角色
材料 → 调试/接入确认 → 数据 → 方案 → 平台执行/可选导出 → 人工复核 → 报告/复测
当前步骤主操作 + 阻断原因 + 缺失材料 + 负责人
主体：表单/数据网格/图像标注/指标/证据
右侧：项目助手（建议/解释/创建草稿，不代替批准）
~~~

允许回看和新建修订，不允许修改冻结内容；修改动作清楚提示影响哪些审批与运行。

## 3. 核心页面操作

- **提测**：上传模板或逐字段填写，cURL 大文本框即时标出不支持项和敏感 header；导入预览、必填错误到行。保存后原 token 不回显，只显示 credential 掩码/替换操作。
- **接口调试台**：method/URL/query/header/auth/body/输入绑定可视编辑，显示环境/Worker 位置；解析预览不联网，批准目的地后“发送一次”。响应 raw/pretty/流式时间线/提取结果与 TLS/鉴权/业务断言分开。确认绑定修订与证据，后续改动提示需重验；HTTP 200 不等于业务正确，更不代表允许压测。
- **数据**：显示授权、真实/合成占比、类别与切片、重复/泄漏、标签冲突。生成是“生成候选”，与“审核通过/冻结”分离；支持抽检与双人复核。
- **QA 复核**：顶部组件名/版本/case/run，三栏输入 Q+上下文 / 输出 A+原响应 / 预期要点+来源定位；可展开自动建议，支持暂存、理由、逐维裁决和提交下一条。待审数不能被通过率掩盖。
- **CV 复核**：原图和标签、框叠加/类别筛选/难例；显示坐标和类别字典版本，不只显示 JSON。
- **方案**：按任务推荐指标，解释适用性；非流式、只有状态流或未启用流式时 TTFT 选项禁用并说明；应可测但未观测到内容时标不可用，不能填 0。阈值、负载档、预算和停止条件有单位及上下限；提交审批后只读。
- **运行**：分别显示执行 status 与验收 verdict，计数/错误/待审/未执行。可取消但不能承诺瞬间停止；取消后保留部分证据。
- **性能**：每档/重复的 mean/p50/p95/p99、TTFT、成功率、QPS、token 来源与整体 TPS、窗口和错误；缺失为“不可用/不适用”，不是 0。
- **导出工程**：从确认接口/冻结方案操作，预览组件/环境/数据范围/裁判与依赖；区分配置骨架、可执行包、仅采集未裁判模式。无权限的金标不打包；生成 Job 可追踪/取消，显示 manifest/自检与适配范围。功能未验收则不显示可用导出按钮。
- **报告**：模板映射、缺项校验、证据链、草稿/审批/发布，导出脱敏；FAIL/BLOCKED 也能产评测记录但不能叫通过报告。
- **整改复测**：问题→责任方→整改说明→新组件版本→同基准全量/子集复测；突出哪些条件变了、是否可比，子集通过不显示项目全量通过。

## 4. 状态、权限和错误体验

PASS/FAIL/NEEDS_REVIEW/BLOCKED 既有颜色也有文字/图标；completed 不用绿色“通过”替代。
加载、空数据、无权限、capability 未启用、离线、429 和任务中断分别提示。错误不能只放 toast；表单可修复，任务失败可定位证据。键盘可用、图片有替代描述、大列表分页/虚拟化。
审批按钮受后端授权，前端隐藏不是安全控制；报告下载同样鉴权。所有敏感 data 不进入浏览器持久缓存或 URL。

## 5. 实施与回归

复用现有 Next.js App Router、TanStack Query、UI 基元；新增 core/evaluation 与 components/evaluation，避免把业务塞进聊天大组件。
服务状态来自 REST，业务 SSE 只更新/失效缓存，重连按 seq 去重；助手继续使用 LangGraph SDK，两种流不混淆。
先问答调试/平台/基础人工复核闭环，再独立导出与跨项目复核增强，后 CV。测试覆盖导航、导入修错、冻结、审批失效、重复点击幂等、断流恢复、取消、缺指标、误 PASS 和脱敏。旧 component-tests 页保留兼容读取或明确迁移引导，不静默丢历史记录。

## 6. 复核中心与关键交互细节

复核中心和数据/结果内嵌详情复用同一 ReviewTask 及组件。列表含组件名/版本、case、Q/A/预期摘要、送审原因/风险/负责人；默认我的待办，支持领取、争议/切片筛选。顶部始终能定位当前组件与样本，避免跨组件误判。

可选动作有通过、不通过、资料不足、参考答案疑错、送专家；动作受 task kind 限制。ERROR/NOT_RUN 不允许人工点通过；性能页不提供编辑数值；金标修订走新数据版本。提交必须显示影响哪些计数/报告，并保留旧判断，不能只 toast“操作成功”。

提交前显示完整必要内容；盲审策略隐藏自动建议/他人决定。键盘可完成但不在文本输入时触发快捷键；长文/图像有缩放、检索、截断提示。多人冲突返回 409 时保留本地草稿并提示重新加载；逾期/失去领取权不能静默提交。批量低风险动作逐条留因，禁止高风险一键全过。

人工重算生成新的 assessment_revision；旧报告仍显示其原引用，并明确提示“复核已变更，需重新审批”，不静默刷新成新结论。细节见[复核工作台](DevPilot_人工复核工作台设计.md)；调试/导出见[专题](DevPilot_接口调试与脚本导出设计.md)。
