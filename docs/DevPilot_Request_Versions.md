# DevPilot 请求定义版本与保护边界

日期：2026-11-08。此轮是评测主线的后端基础切片，不是完整执行引擎。

## 为什么要增加这一层

cURL 调试器已经可以解析、编辑和发送一次请求；参数化模板也可以导出。但旧组件记录仍可能随时修改，请求模板只描述连线，不保存真实值，因此不能作为后续复测的固定输入。

新增项目下的**请求定义版本**：一个项目包含多个组件，一个组件可以保存多个只追加的请求版本。其范围固定为 `request_definition_only`，不是已批准的执行计划、调试成功证明或报告证据。

## 本轮实现

- 纯领域 `devpilot.request_versions.FrozenRequest`：深不可变 tuple 请求头，导入/导出防御性复制，保留请求体与头值空白；无环境、磁盘或网络访问。受保护序列化包含真实值，禁止当公共响应使用。
- App 层对**完整 URL（含路径/查询）、全部请求头值、请求体**进行 Fernet 认证加密。不靠猜测某几个敏感头名称来保护，也不保存真实值的公开哈希。
- 密文绑定 owner、项目、组件和请求版本 ID；移植到其他版本或上下文不能解密。打开时重验密文摘要、受保护绑定和结构模板。
- 公共元数据包括版本 ID、标签、时间、创建者、结构模板和密文摘要；SQL 明确不选择密文字段。结构模板仍包含目标 origin、方法及头名称，**不是全匿名数据**。
- 保存、内部打开的元数据审计与业务操作同事务提交；审计不写入请求值。加解密通过线程离开事件循环。
- App 迁移链新增 `eval_0003`，保持已部署的 `eval_0001/eval_0002` 不变，不改 Harness ledger。

## API

基路径：`/api/evaluation/projects/{project_id}`。

| 方法与后缀 | 权限/边界 |
| --- | --- |
| POST `/components/{component_id}/request-versions` | write + review、本人项目/组件、明确 boolean confirmed；拒绝内部 Agent 调用 |
| GET `/components/{component_id}/request-versions` | read；仅元数据 |
| GET `/request-versions/{version_id}` | read；仅元数据 |
| GET `/request-versions/{version_id}/audit` | review；仅元数据 |

请求严格校验；错误不回显输入，响应 private/no-store。请求体有总大小上限。版本标签 NFKC/空白/大小写归一后在组件内唯一；重复并发保存仅一份成功。没有更新、删除、明文打开或直接执行的 HTTP 路由。

## 密钥及部署

运维通过 **DEVPILOT_REQUEST_ENCRYPTION_KEY** 显式提供 Fernet key。与模型目录密钥、JWT secret 分离；不自动生成、不复用已有凭据，不从用户 API 修改。缺失或格式错误时保存返回通用 503，但已有元数据读取不依赖该密钥。实际内部解密也必须有原密钥。

新环境可用 Python cryptography 的 Fernet.generate_key() 生成密钥，然后通过本地受控 secret/env 注入 Gateway。**不要把密钥、真实 cURL、数据库、备份或运行配置提交到 Git。** 密钥需要独立备份；丢失则无法恢复旧值。当前尚无在线换钥、批量重加密或凭据撤销管理，不能直接替换密钥后假定旧版本仍可运行。

本轮不擅自修改本地既有运行配置或创建新密钥；本地没有配置新 key 时，新增保存能力按上述规则关闭，助手、已有项目/数据集/调试仍可用。

## 限制与下一步

1. 这是后端 API 切片，尚未增加调试器“保存版本”按钮；不能宣称 UI 已接通。
2. 这里整体加密请求值，不是可复用凭据引用仓库，也没有向 Agent 暴露解密工具。
3. 没有网络请求、目标批准、成功调试认证、执行预算/批准、取消、Worker 租约或流式测量；保存一个目标不代表目标可调用。实际发送仍须重新检查出站策略与当次同意。
4. “只追加”是应用路由/服务约束，不是防数据库管理员修改的不可篡改存储；密文摘要不是签名。没有正式报告发布或验收结论。
5. 下一步连接请求版本、冻结 QA revision/hash、明确样本绑定与效果/性能参数，构建冻结计划；然后实现耐久 Worker、逐条观测和人工复核。TTFT 只对实测内容流适用，缺失不能记为零。
6. 真实 PostgreSQL、真实外部组件和付费模型验收尚未完成。
